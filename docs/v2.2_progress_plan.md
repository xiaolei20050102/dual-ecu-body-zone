## 使用规则

每次确定项目下一步前，必须同时对照以下三份文件：

1. `outputs/auto_ecu_project/双ECU车身区域控制诊断刷写实验平台_项目说明书_v2.2.pdf`：冻结的项目范围、架构、阶段出口与验收目标。
2. 本文件：已经完成的实际证据、当前唯一任务、下一任务依赖和变更记录。
3. `AGENTS.md`：协作方式、任务边界、验证与停止规则。

判定原则：PDF 决定“做什么、不做什么”；本文件决定“目前做到哪里、下一步是什么”；`AGENTS.md` 决定“如何推进”。三者冲突时，停止实施，先记录冲突和最小修订理由。

## 冻结主线

`PC CAN -> S32K144 Main ECU -> LIN -> STM32F411 Actuator ECU -> TB6612FNG + N20 Encoder Motor + Dual Limit Switches -> CAN-LIN Gateway -> UDS/DTC/NvM -> CAN Bootloader`

## 已完成的配置冻结项

### W2-L1-00：F411 CubeMX 配置冻结

目标：在不实现后续业务逻辑的前提下，一次性冻结 W2/W3 已确定的时钟、引脚、FreeRTOS 空任务和中断优先级，避免后续 `.ioc` 引脚冲突或生成代码结构变化。

允许修改：

- `firmware_f411/f411_actuator_ecu/*.ioc`（正式工程的 CubeMX 配置）

冻结范围：100 MHz 时钟；TIM1 PWM、TIM2 Encoder、TB6612 GPIO、双限位 EXTI、USART1 日志、USART2 LIN；FreeRTOS CMSIS_V2 与空的 `SafetyTask`、`ControlTask`。

限制：此项只生成外设和任务骨架；不实现编码器、限位、LIN、状态机或业务逻辑，不将其标记为功能完成。

验收：Clock Configuration 无错误；已知引脚无冲突；FreeRTOS 任务与中断优先级生成；Keil 构建 0 Error/0 Warning。

完成证据（2026-07-28）：

- 正式工程已生成：`firmware_f411/f411_actuator_ecu`。
- TIM1 PWM、TIM2 Encoder、限位 EXTI、USART1、USART2 LIN、TIM3 HAL 时基、CMSIS_V2 FreeRTOS 已生成。
- `ControlTask`（512 Words）与 `SafetyTask`（256 Words）已生成；`heap_4` 为 32768 Bytes。
- `vApplicationStackOverflowHook()` 与 `vApplicationMallocFailedHook()` 已实现最小安全动作：PWM=0、STBY=0、关中断并停机。
- Keil 构建结果：`0 Error(s), 0 Warning(s)`。

## 当前唯一任务

### W2-L1-01：电机驱动模块化

目标：将已验证的 F411 电机测试逻辑从 `main.c` 封装为可复用驱动模块，禁止应用层直接操作 PWM 寄存器或 TB6612 GPIO。

允许修改：

- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_types.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_port.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_port_stm32.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_driver.h`
- `firmware_f411/f411_actuator_ecu/BSP/Src/motor_port_stm32.c`
- `firmware_f411/f411_actuator_ecu/BSP/Src/motor_driver.c`
- `firmware_f411/f411_actuator_ecu/Core/Src/main.c`

接口最小范围：`Motor_Init()`、`Motor_SetDuty()`、`Motor_SetDirection()`、`Motor_Stop()`、`Motor_Disable()`。

数据流：`main.c 测试序列 -> motor_driver API -> TIM1_CH1 / PB0 / PB1 / PB10 -> TB6612FNG -> N20`。

安全规则：初始化和错误出口必须 `PWM=0`；方向改变前必须先停止；`Motor_Disable()` 必须拉低 STBY。

验收：Keil 构建 0 Error/0 Warning；下载后保持“正转 2 s -> 停 1 s -> 反转 2 s -> 停 1 s”；`main.c` 中不再直接操作 TIM1 比较值或 PB0/PB1/PB10。

完成后记录：构建截图/日志、实物动作视频或照片、实际改动文件、已知限制。
