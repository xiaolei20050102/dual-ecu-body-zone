## 使用规则

每次确定项目下一步前，必须同时对照以下三份文件：

1. `outputs/auto_ecu_project/双ECU车身区域控制诊断刷写实验平台_项目说明书_v2.2.pdf`：冻结的项目范围、架构、阶段出口与验收目标。
2. 本文件：已经完成的实际证据、当前唯一任务、下一任务依赖和变更记录。
3. `AGENTS.md`：协作方式、任务边界、验证与停止规则。

判定原则：PDF 决定“做什么、不做什么”；本文件决定“目前做到哪里、下一步是什么”；`AGENTS.md` 决定“如何推进”。三者冲突时，停止实施，先记录冲突和最小修订理由。

## 冻结主线

`PC CAN -> S32K144 Main ECU -> LIN -> STM32F411 Actuator ECU -> TB6612FNG + N20 Encoder Motor + Dual Limit Switches -> CAN-LIN Gateway -> UDS/DTC/NvM -> CAN Bootloader`

## 已完成的配置冻结项

### W2-L1-00：F411 CubeMX 配置冻结

目标：在不实现后续业务逻辑的前提下，一次性冻结 W2/W3 已确定的时钟、引脚、FreeRTOS 空任务和中断优先级，避免后续 `.ioc` 引脚冲突或生成代码结构变化。

允许修改：

- `firmware_f411/f411_actuator_ecu/*.ioc`（正式工程的 CubeMX 配置）

冻结范围：100 MHz 时钟；TIM1 PWM、TIM2 Encoder、TB6612 GPIO、双限位 EXTI、USART1 日志、USART2 LIN；FreeRTOS CMSIS_V2 与空的 `SafetyTask`、`ControlTask`。

限制：此项只生成外设和任务骨架；不实现编码器、限位、LIN、状态机或业务逻辑，不将其标记为功能完成。

验收：Clock Configuration 无错误；已知引脚无冲突；FreeRTOS 任务与中断优先级生成；Keil 构建 0 Error/0 Warning。

完成证据（2026-07-28）：

- 正式工程已生成：`firmware_f411/f411_actuator_ecu`。
- TIM1 PWM、TIM2 Encoder、限位 EXTI、USART1、USART2 LIN、TIM3 HAL 时基、CMSIS_V2 FreeRTOS 已生成。
- `ControlTask`（512 Words）与 `SafetyTask`（256 Words）已生成；`heap_4` 为 32768 Bytes。
- `vApplicationStackOverflowHook()` 与 `vApplicationMallocFailedHook()` 已实现最小安全动作：PWM=0、STBY=0、关中断并停机。
- Keil 构建结果：`0 Error(s), 0 Warning(s)`。

## 已完成的 W2 任务

### W2-L1-01：电机驱动模块化

目标：将已验证的 F411 电机测试逻辑从 `main.c` 封装为可复用驱动模块，禁止应用层直接操作 PWM 寄存器或 TB6612 GPIO。

允许修改：

- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_types.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_port.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_port_stm32.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/motor_driver.h`
- `firmware_f411/f411_actuator_ecu/BSP/Src/motor_port_stm32.c`
- `firmware_f411/f411_actuator_ecu/BSP/Src/motor_driver.c`
- `firmware_f411/f411_actuator_ecu/Core/Src/main.c`
- `firmware_f411/f411_actuator_ecu/Core/Src/freertos.c`（仅 `ControlTask` 的临时模块验收序列）

接口最小范围：`Motor_Init()`、`Motor_SetDuty()`、`Motor_SetDirection()`、`Motor_Stop()`、`Motor_Disable()`。

数据流：`main.c 测试序列 -> motor_driver API -> TIM1_CH1 / PB0 / PB1 / PB10 -> TB6612FNG -> N20`。

安全规则：初始化和错误出口必须 `PWM=0`；方向改变前必须先停止；`Motor_Disable()` 必须拉低 STBY。

验收：Keil 构建 0 Error/0 Warning；下载后稳定完成“正转 -> 停 -> 反转 -> 停”循环，正反转与停机时长可按观察需要配置；`main.c` 中不再直接操作 TIM1 比较值或 PB0/PB1/PB10。

完成后记录：构建截图/日志、实物动作视频或照片、实际改动文件、已知限制。

完成证据（2026-08-02）：

- `ControlTask` 经 `Motor_Init()`、`Motor_SetDirection()`、`Motor_SetDuty()`、`Motor_Enable()` 与 `Motor_Stop()` 驱动电机；应用代码未直接操作 TIM1 比较值或 TB6612 GPIO。
- 用户确认 Keil 编译通过，下载后以“正转 10 s -> 停 1 s -> 反转 10 s -> 停 1 s”完成硬件循环。
- 已知限制：本次验收未单独归档电机动作视频/照片；后续阶段的演示证据需单独保存。

## 已完成的 W2 任务

### W2-L1-02：编码器驱动（位置快照）

目标：将已冻结的 TIM2 编码器模式（PA0/PA1，A/B 相）封装为独立驱动，向 `ControlTask` 提供可读取的有符号位置快照；本任务不实现速度估算、零点标定、限位联动或闭环控制。

允许修改：

- `firmware_f411/f411_actuator_ecu/BSP/Inc/encoder_types.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/encoder_port.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/encoder_port_stm32.h`
- `firmware_f411/f411_actuator_ecu/BSP/Inc/encoder_driver.h`
- `firmware_f411/f411_actuator_ecu/BSP/Src/encoder_port_stm32.c`
- `firmware_f411/f411_actuator_ecu/BSP/Src/encoder_driver.c`
- `firmware_f411/f411_actuator_ecu/Core/Src/freertos.c`（仅 `ControlTask` 的临时读数验证）

数据流：`N20 编码器 A/B 相 -> TIM2 Encoder Mode（PA0/PA1）-> encoder_port -> encoder_driver -> ControlTask 位置快照`。

安全规则：编码器驱动只读计数，不直接驱动电机；读数异常或溢出处理策略先定义接口与状态，不在本任务中接入电机安全停机。

验收：Keil 构建 `0 Error(s), 0 Warning(s)`；正反向转动时位置快照单调增/减；可在 Keil Watch 或 USART1 日志中读到稳定位置值。

停止条件：仅完成位置计数的驱动与验证；不进入速度计算、限位、状态机或 LIN。

完成证据（2026-08-04）：

- 编码器模块已接入 `ControlTask`：`Encoder_Init()` 在电机启动前执行，随后每 10 ms 调用 `Encoder_Update()` 与 `Encoder_GetSnapshot()`。
- 用户确认 Keil 编译、下载并调试成功；Watch 可读取 `g_encoder_snapshot.position_count` 与 `g_encoder_snapshot.raw_count`。
- 正转时位置值从 `0x00000000` 增至 `0x00007020`；反转的自动停止测试结束前，位置值为 `0xFFFF4C4A`，即有符号累计位置为负数，正反方向均已验证。
- 验证过程中不在电机运行时长期停在编码器读取断点，避免硬件继续计数而软件暂停更新造成的计数跨界歧义。

## 已完成的 W2 任务

### W2-L1-03：双限位输入驱动与去抖

目标：将已冻结的 `LIMIT_OPEN_N`（PB12）与 `LIMIT_CLOSE_N`（PB13）主动低限位输入封装为独立模块，向后续执行器状态机提供稳定的开到位、关到位与双限位矛盾状态。

数据流：`双限位开关 -> PB12/PB13 GPIO 输入 -> limit_port -> limit_driver -> ControlTask 状态快照`。当前功能由 `ControlTask` 周期读取与去抖确认；EXTI 配置保留，但不作为本任务的状态上报路径。

本任务边界：先完成输入读取、主动低语义统一、去抖和双限位同时有效的故障状态；不提前实现完整执行器状态机、LIN 或闭环控制。电机到限停车将在限位状态稳定后作为本地安全链路的直接验证项。

完成证据（2026-08-11）：

- 用户确认 Keil 编译通过；`ControlTask` 每 10 ms 调用 `Limit_Update()` 与 `Limit_GetSnapshot()`，驱动采用连续 3 次一致采样的软件去抖。
- USART1（PA9，115200 8N1）已用于仅在稳定状态变化时输出日志；已排除初次无日志的电脑端串口端口选择问题。
- 用户逐项验证并提供串口日志：`NONE`、`OPEN_ACTIVE`、`CLOSE_ACTIVE` 与 `CONFLICT` 均能稳定出现，随后恢复为 `NONE`；双限位矛盾状态可观测。
- 本项仅验证输入、去抖和状态上报；尚未接入电机到限停车、限位矛盾停车、编码器异常或命令超时的本地安全动作。

## 当前唯一任务

### W2-L1-04：F411 本地安全与执行器状态机

目标：在任务上下文中消费编码器快照与稳定限位状态，为执行器建立最小状态机；当到达对应方向限位、两限位矛盾、编码器更新失败或命令超时时，先执行 `Motor_Stop()` 与 `Motor_Disable()`，再记录故障状态。通信恢复后不得自动恢复危险动作。

数据流：`动作命令 -> 执行器状态机 -> Motor_* -> TB6612FNG`；`编码器/限位/超时 -> 本地故障判定 -> 停车与失能 -> 状态日志`。

本任务边界：先完成 F411 单板的本地安全闭环；不接入 LIN、CAN 网关、UDS 或 DTC 持久化。

验收：正转触发开到位即停、反转触发关到位即停；双限位矛盾、编码器异常与命令超时均使 PWM=0、STBY=0；故障触发与停车结果可由 USART1 日志和硬件行为证明。

停止条件：本地安全闭环通过后，才进入 5 ms 任务测量与 FreeRTOS 运行证据；不提前开始 LIN。
